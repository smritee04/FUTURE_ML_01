# FUTURE_ML_01 – Sales & Demand Forecasting

## 📌 Task Overview
This project focuses on forecasting future sales using historical retail data as part of the **Machine Learning Internship at Future Interns**.

## 📊 Dataset
- **Superstore Sales Dataset**
- Contains order-level retail sales information

## 🛠️ Tools & Libraries
- Python
- Jupyter Notebook (VS Code)
- Pandas, NumPy
- Matplotlib
- Statsmodels (Holt-Winters)
- Scikit-learn (evaluation)

## 🔍 Methodology
1. Data cleaning and preprocessing  
2. Monthly sales aggregation  
3. Time-series forecasting using Holt-Winters Exponential Smoothing  
4. Model evaluation using MAE  
5. Visualization of trends and forecasts  

## 📈 Results
- Successfully captured trend and seasonality
- Generated a 12-month future sales forecast
- Provided business-friendly visual insights
